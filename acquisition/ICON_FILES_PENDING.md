# Graphical icons excluded from the public-source candidate

The uploaded `icons.zip` contains images of commercial devices. Their origin and permission to redistribute are not established, so the GitHub candidate **does not include the PNG images**.

The acquisition GUI currently references these filenames from the relative folder `icons/`:

- `Generator_Agilent.png`, `Generator_Agilent_grey.png`
- `Wattmeter_RohdeSchwarz.png`, `Wattmeter_RohdeSchwarz_grey.png`
- `Motion_Controller.png`, `Motion_Controller_grey.png`
- `Picoscope.png`, `Picoscope_grey.png`

Obtain permission or replace them with self-made non-infringing graphics before public release. The original ZIP remains only among the private uploaded materials, not in this repository.
